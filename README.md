# ⚓🏴‍☠️ One Piece Anime Portfolio

A **beginner-friendly React portfolio website** inspired by the world of **One Piece** 🏴‍☠️.
This project blends **frontend fundamentals** with a fun anime-style UI to make learning React more engaging.

---

## 🚀 Features

* 🌐 Multi-page React application
* ♻️ Reusable and modular components
* 📁 Clean and beginner-friendly folder structure
* 🎨 Anime-inspired user interface
* 💼 Portfolio / project showcase section
* 👥 Crew (team) page
* 📬 Contact page
* ✨ Simple and clean design

---

## 🛠️ Tech Stack

* ⚛️ React.js
* ⚡ Vite
* 🟨 JavaScript (ES6)
* 🧱 HTML5
* 🎨 CSS3
* 🔀 React Router

---

## ▶️ Getting Started

Follow these steps to run the project locally:

### 1️⃣ Install dependencies

```bash
npm install
```

### 2️⃣ Start development server

```bash
npm run dev
```

### 3️⃣ Open in browser

```
http://localhost:5173
```
