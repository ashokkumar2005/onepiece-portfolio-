# One Piece Anime Portfolio ⚓🏴‍☠️

This is a **beginner React portfolio website** inspired by the One Piece anime.
The project demonstrates basic React concepts like components, routing, and styling.

## 🚀 Features

* Multi-page React website
* Separate components for each page
* Beginner friendly code structure
* Anime themed UI
* Portfolio project section
* Contact page

## 🛠 Technologies Used

* React
* Vite
* JavaScript
* HTML
* CSS
* React Router

## 📂 Project Structure

src/

* components/

  * Navbar.jsx
* pages/

  * Home.jsx
  * About.jsx
  * Projects.jsx
  * Crew.jsx
  * Contact.jsx
* App.jsx
* main.jsx

## ▶ Run the Project

Install dependencies

npm install

Start development server

npm run dev

Then open

http://localhost:5173
